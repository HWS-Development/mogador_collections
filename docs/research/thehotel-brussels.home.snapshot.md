# The Hotel Brussels Homepage Snapshot Notes

Captured via Centra browser snapshot on `https://www.thehotel-brussels.be/fr/`.

## Topology Observed
1. Fixed hero with centered logo, language switcher, booking CTA.
2. Full viewport hero slider: 3 banners, large uppercase title, centered `Découvrir` CTA, previous/next controls.
3. Editorial intro: destination framing, large heading, paragraphs, CTA to rooms.
4. Rooms and suites section: image/video media, room carousel, vertical room list, pricing, CTAs.
5. Spa/fitness split: image + copy + two CTAs.
6. Events split: copy + CTA + image.
7. Dining/gallery carousel: image carousel + restaurant copy.
8. Destination/local attractions: heading + horizontal cards carousel.
9. Sustainability split.
10. Rich footer with language/social/contact/navigation.

## Behaviors Observed
- Hero and room sections are time/click-driven carousels.
- Room section uses a vertical list of room tabs plus active slide.
- Section CTAs are direct and uppercase.
- Layout alternates image/copy rhythm.
- Footer/menu duplicate navigation for conversion and discovery.
